## Project Description

PlayMatch is a web platform that combines "Play" and "Match" to help users easily find and connect for soccer and futsal games. The platform provides AI-based player matching and reservation system for sports facilities.

## Problem Statement & Goals

### Current Problems:
1. Lack of automatic player matching functionality
2. Difficulty in real-time communication for sports meetups
3. Absence of trustworthy matching systems based on skills and reliability

### Project Goals:
- Provide location-based automatic team/player matching
- Enable real-time communication between players and team leaders  
- Implement AI-powered player recommendation system
- Create comprehensive review and rating system for players, teams, and facilities

## System Architecture

### User Types:
1. **Individual Players** - People looking to join games as mercenaries
2. **Team Leaders** - Users who organize teams and recruit players
3. **Facility Managers** - Stadium/field operators managing reservations

### Core Features:

#### Individual Player Features:
- Location-based game search
- Mercenary participation application
- Player review and rating system
- Real-time chat functionality
- Feedback board for sharing play videos
- Chatbot-assisted profile creation

#### Team Leader Features:
- Game creation and team recruitment
- Skill and position-based player search
- Team invitation system
- Post-game team management
- Player review and rating

#### Facility Manager Features:
- Facility registration and information management
- Reservation management system
- Game approval/cancellation management
- User feedback monitoring

## Database Design

### Key Entities:
- **User** - Core user information with sports profiles
- **Team** - Team information and leadership
- **Facility** - Sports venue details and availability
- **Match** - Game information and scheduling
- **MatchParticipant** - Player participation in games
- **Reserve** - Facility booking system
- **PlayerMatching** - AI-powered player recommendations
- **PlayerStats** - Player performance tracking
- **Review** - Multi-directional rating system
- **ChatRoom & Chat** - Real-time messaging system

## AI Recommendation System

### Technology: KNN (K-Nearest Neighbors) Algorithm
### Features:
- Position-based player matching
- Skill level compatibility
- Play style matching
- Location proximity consideration
- Performance history analysis
