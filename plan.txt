# 2. 요구사항 정의서

## 2.1 기능 요구사항

### 2.1.1 주요 기능
| 기능명 | 설명 |
|--------|------|
| 회원가입 및 로그인 | 이메일 기반 회원가입/로그인, 사용자 유형 선택 (개인, 팀 리더, 구장 관리자) |
| 프로필 작성 | 개인, 팀, 구장 프로필 작성 화면 제공 및 분기 처리 |
| 경기 생성 | 팀 리더가 경기 일시, 장소, 유형 등을 입력하여 등록 |
| 경기 조회 및 신청 | 개인 참가자가 공개된 경기를 리스트로 확인하고 신청 |
| AI 추천 기능 | 팀 리더가 입력한 조건(포지션, 실력 등)에 따라 AI가 참가자 추천 (KNN 기반) |
| 채팅 기능 | 매칭된 참가자와 팀 리더 간 채팅 가능 |
| 경기장 등록 | 구장 관리자가 경기장 및 예약 가능한 시간 등록 |
| 예약 관리 | 예약 신청 내역을 구장 관리자가 승인/거절 |
| 리뷰 시스템 | 경기 종료 후 팀 ↔ 개인, 개인 ↔ 구장 등 상호 평가 |
| 이벤트 홍보 | 구장 관리자가 이벤트를 등록하여 사용자에게 노출 |

### 2.1.2 비기능 요구사항

1. **성능**
- 응답 시간: 웹페이지 로딩은 2초 이내여야 함.
- 동시 사용자 처리: 최대 500명 이상의 동시 접속자도 원활히 처리 가능해야 함.
- 검색 속도: 경기나 구장 검색 시 2초 이내 결과 표시가 되어야 함.

2. **보안**
- 데이터 보호: 사용자의 개인정보(이메일, 비밀번호 등)는 암호화 저장해야 함.
- 인증 및 권한 관리: 강력한 인증 시스템 도입, 관리자와 일반 사용자 권한 명확히 구분.
- HTTPS 사용: 모든 페이지는 HTTPS 프로토콜로 통신해야 함.

3. **가용성**
- 업타임: 웹사이트의 가용성은 99.9% 이상이어야 함.
- 데이터 백업: 사용자 데이터는 정기적 백업, 손실 시 복구 절차 마련 필요.

4. **호환성**
- 브라우저 호환성: Chrome, Firefox, Safari, Edge 등 주요 브라우저에서 정상 작동.
- 운영 체제 호환성: Windows, macOS, Linux 등 다양한 OS에서도 정상 사용 가능.

5. **유지보수성**
- 코드의 가독성: 구조화된 코드, 명확한 주석 포함. 다른 개발자가 쉽게 이해 및 수정 가능.
- 버전 관리: Git 등 시스템을 활용한 코드 관리 필수.
- 테스트 가능성: 기능 단위 테스트와 자동화된 통합 테스트 가능해야 함.


## 2.2 주요 기능

### 1. 개인 사용자
축구 또는 풋살을 즐기고 싶은 일반 유저 대상.

**주요 기능**
- 위치 기반 경기 검색
- 용병 참가 신청
- 팀원 리뷰 및 평점 작성
- 실시간 채팅
- 피드백 게시판 (플레이 영상 공유, 조언)
- 챗봇을 통한 프로필 입력 지원

### 2. 팀 리더 사용자
팀을 구성하고 인원을 모집하는 경기 주최자 대상.

**주요 기능**
- 경기 생성 및 팀원 모집
- 실력/포지션 기반 용병 검색
- 팀 초대 기능
- 팀 관리 기능 (경기 후 구성 관리)
- 팀원 리뷰 및 평점 작성

### 3. 구장 사업 관리자
풋살장/축구장 예약 시스템 관리자.

**주요 기능**
- 구장 등록 및 정보 수정
- 예약 관리 (승인/거절)
- 경기 승인 및 취소 관리
- 사용자 후기 모니터링 및 서비스 개선
